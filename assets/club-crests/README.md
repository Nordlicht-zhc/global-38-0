# Club crests

Local PNG badges from [luukhopman/football-logos](https://github.com/luukhopman/football-logos), supplemented by club badge images from Wikipedia/Wikimedia. `sources.json` records the original paths and repository revision for GitHub assets, and the club pages, image filenames and download URLs for Wikipedia assets. Club badges and trademarks belong to their respective owners; inclusion does not imply endorsement.

The interface uses one badge per club identity across seasons, rather than claiming to reproduce every historical badge variant. Exact name and ID aliases live in `src/club-crests.js`. Unknown clubs use a shield with initials; the custom user team uses a 38 shield, and Club Peak uses the selected club badge. No image requests to external services occur during play.
