# Global 38-0｜全球全明星赛季

[简体中文](README.md) | [English](README.en.md)

一款支持中英文的足球选秀与赛季模拟游戏。跨赛季挑选球员，组建首发十一人，争夺联赛、国内杯赛和欧洲赛事冠军。

**[在线游玩](https://nordlicht-zhc.github.io/global-38-0/) · [下载 Windows 便携版](https://github.com/Nordlicht-zhc/global-38-0/releases/latest)**

## 主要功能

- **跨赛季选秀**：从五大联赛不同赛季的俱乐部阵容中选择球员，自定义赛季、联赛范围和难度。
- **阵容经营**：调整阵型、聘请教练，通过转会、自由签约和租借补强球队。
- **赛事模拟**：参加联赛、国内杯赛与欧洲赛事，查看积分榜、比赛结果和球员统计。
- **三种模式**：经典模式挑战单赛季冠军，挑战模式完成特殊目标，王朝模式跨赛季经营并体验三级征途升降级。
- **成就与存档**：解锁成就、查看历史战绩，自动保存本地进度；经典／挑战模式与王朝模式分别存档。
