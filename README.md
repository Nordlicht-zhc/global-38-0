## 从一次抽取，到一个冠军赛季

- **跨时代选秀**：从 1994-95 至 2026-27 赛季的五大联赛阵容中挑选球员，让不同时代的球星并肩作战。
- **亲手经营球队**：调整阵型、选择教练，通过转会、自由签约与租借补齐阵容短板。
- **征战完整赛事**：参加联赛、国内杯赛和欧洲赛事，通过积分榜、赛果与球员统计回顾球队表现。
- **留下你的战绩**：解锁成就、保存赛季记录，自动保存本地进度；经典／挑战与王朝模式分别存档。

## 选择你的征途

| 经典模式 | 挑战模式 | 王朝模式 |
